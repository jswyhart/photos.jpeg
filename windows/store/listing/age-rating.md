The app is a tool; it has no content of its own.

| Question area | Answer | Why |
|---|---|---|
| Violence, fear, sexual content, nudity, language, drugs, gambling | None | The app ships no content |
| Users can interact or exchange content with other users | No | No accounts, no sharing features |
| Shares the user's location with other users | No | GPS positions in photos are shown on a map only to the user |
| Allows purchases of digital goods | No | |
| Unrestricted internet access or a web browser | No | |
| Collects personal information | No | See privacy.md |

Expected outcome: suitable for all ages (IARC 3+, ESRB Everyone).
